<objective>
Close the round trip: a mutation API that records an edit against a resolved source span, and a
writer that rewrites only the files carrying an edit, by splicing the replacement text into the
original bytes rather than re-emitting the file (YAML-04, YAML-02, D-01, D-02, D-03).

Purpose: this is the decision the whole phase exists to honour. A ruamel dump of a touched file
silently reflows block sequences and normalises style; a splice against the span index changes
the bytes the user asked to change and nothing else. Files with no edit are never opened for
writing at all, which is how YAML-02's "load then dump is byte-identical" is actually satisfied.

Output: `src/haco/configtree/writer.py`, `ConfigTree.set()` and `dirty_files()` in
`src/haco/configtree/tree.py`, `UnspliceableNodeError` in `src/haco/errors.py`, and
`tests/test_configtree_writer.py`.
</objective>

## Style-to-render mapping (D-02)

`render_scalar` branches on the `SpanKind` recorded by `build_span_index` in 02-01 Task 3, and
re-wraps the new value in ruamel's matching scalar-string class before rendering it:

| `SpanKind` | Replacement text shape |
|---|---|
| `plain` | the bare value, no quotes, no trailing whitespace, no trailing newline |
| `single` | wrapped in single quotes with ruamel's own escaping |
| `double` | wrapped in double quotes with ruamel's own escaping |
| `literal` | the block indicator, the body indented to the original node's column, and one trailing newline - the span ends after that newline |
| `folded` | the fold indicator, the body indented to the original node's column, and one trailing newline |
| `flow` | the bracketed or braced flow form on one line |
| `tagged` | the original tag text followed by the new argument |
| `collection` | not renderable in this phase - `set()` on a block collection raises `UnspliceableNodeError` |

The literal and folded rows are the ones RESEARCH.md Pitfall 3 warns about: for those kinds
`end_mark.index` sits at column zero of the following line, so a replacement without its trailing
newline runs the next line into the block.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-memory edit -> file bytes on disk | The only point in this phase where the process writes; a mistake here corrupts a real config |
| caller-supplied replacement value -> rendered YAML text | Untrusted value crosses into a file that Home Assistant will parse |
| temp file -> target path | The window in which a partially written file could be observed or left behind |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10 | Tampering (silent config corruption) | `writer.splice` offset arithmetic | high | mitigate | Edits are applied sorted by start descending so no applied edit invalidates a pending offset; `test_splice_span_touches_only_target` is parametrized per scalar kind and asserts the original prefix and suffix around the span are byte-identical, so a one-character arithmetic error fails a test rather than reaching a config file |
| T-02-11 | Tampering | alias-shared node edited in two places at once | high | mitigate | `ConfigTree.set` refuses any span carrying the `unspliceable` reason recorded during the 02-01 compose walk, raising `UnspliceableNodeError` naming the anchor before anything is marked dirty; proved by `test_ambiguous_span_fails_loud_alias` |
| T-02-12 | Tampering (partial-file exposure) | `writer.atomic_write` | medium | mitigate | `tempfile.mkstemp` in the target's own directory plus `os.replace` makes the swap atomic on the same filesystem; the temp file is unlinked on any exception; the target is never truncated in place, so an interrupted run can never leave Home Assistant a half-written config |
| T-02-13 | Tampering (injection into rendered YAML) | `writer.render_scalar` | high | mitigate | Escaping is delegated entirely to ruamel's scalar-string classes rather than hand-rolled, so a replacement value containing quotes, backslashes, newlines or a leading tag, anchor or alias character cannot break out of its scalar and inject structure into the file; the double-quote escaping case is asserted in Task 2 |
| T-02-14 | Information Disclosure | temp file contents and permissions | low | accept | `mkstemp` creates the file with owner-only permissions in the config directory itself rather than a shared temp location; this phase writes only to a local fixture or working copy, and Phase 5 owns writing to the live host |
| T-02-15 | Repudiation | which files a run rewrote | low | mitigate | `flush` returns the tuple of paths it wrote, giving the later session-log requirement a truthful record rather than an inferred one |
