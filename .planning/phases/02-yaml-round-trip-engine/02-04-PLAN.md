<objective>
Prove the engine is a fixed point. With no analysis engine in existence yet, YAML-05's
"re-running analysis yields zero proposed changes" is asserted at the engine level as D-10's
three no-op stability properties, exercised against the whole representative fixture tree rather
than a single toy file.

Purpose: every later phase - the rule optimizer, the diff review loop, the staging and apply
spine - assumes that running the engine over an unchanged tree changes nothing. If that is false,
every diff those phases produce carries engine noise the user has to review, and the apply stage
commits churn. This plan is where that assumption is turned into a test that fails loudly.

Output: `tests/test_configtree_idempotency.py` and, if not already present from 02-02,
`ConfigTree.source_text()` so a mutation can be reverted to its exact original bytes.
</objective>
