<objective>
Build the single-file foundation of the YAML round-trip engine: a pinned `ruamel.yaml`
round-trip loader that parses HA custom tags without error (YAML-01), and a `compose()`-based
span index that gives every editable node an exact `(start, end)` character offset into its
file's original text (D-01). Ship the Wave 0 fixture trees that gate every other plan in this
phase.

Purpose: D-01 requires surgical text splicing, and splicing is impossible without unambiguous
source-byte provenance on every node. That provenance must exist from the very first load path
- retrofitting it later would touch the loader, the mutation API and every write test (the
CONTEXT.md `costly` rating on D-01). This plan establishes it and proves it against a real
HA-shaped config tree.

Output: `src/haco/configtree/{__init__,loader,spans}.py`, the `ConfigTreeError` / `YamlError`
families in `src/haco/errors.py`, the `tests/fixtures/ha_config/` and
`tests/fixtures/ha_config_bad/` trees, the `ha_config_tree` / `ha_config_bad` conftest fixtures,
`tests/test_configtree_loader.py`, `tests/test_configtree_spans.py`, and a narrowed
`ruamel.yaml` constraint in `pyproject.toml`.
</objective>
