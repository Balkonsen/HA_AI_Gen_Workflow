<task type="auto">
  <name>Task 2: HostFacts + discover()</name>
  <files>src/haco/discover.py, src/haco/errors.py</files>
  <read_first>src/haco/hosttypes.py, src/haco/ssh.py</read_first>
  <action>
    Add DiscoveryError(HacoError) to errors.py.
    In discover.py define a frozen dataclass HostFacts: install_type, config_dir,
    config_check_cmd, restart_cmd, container_name: str | None, notes: list[str].
    async detect_type(client) -> InstallType | None :
      run "command -v ha"  -> if exit 0 -> haos
      else run "command -v docker" -> if 0, run
        "docker ps --format '{{.Names}} {{.Image}}'" and match a name/image containing
        "homeassistant" or "home-assistant" -> container (remember the name)
      else run "command -v hass" -> if 0 -> core (venv_bin = dirname of the path)
      else None
    async resolve_config_dir(client, candidates) -> str | None :
      for c in candidates: run f"test -d {shlex.quote(c)} && test -f {c}/configuration.yaml"
      return first hit.
    async discover(client, profile) -> HostFacts :
      itype = profile.install_type or await detect_type(...); if still None raise
        DiscoveryError("could not determine install type - set install_type in the profile").
      For container, container_name = profile.container_name or discovered; if None raise
        DiscoveryError. Derive the bind-mount host path via
        "docker inspect -f '{{range .Mounts}}{{.Source}}:{{.Destination}} {{end}}' NAME"
        and pick the Source whose Destination is /config.
      config_dir = profile.config_dir or await resolve_config_dir(...); if None raise
        DiscoveryError with the candidates tried.
      Build ctx and compute check/restart from DEFAULTS[itype], then apply overrides:
      config_check_cmd = profile.config_check_cmd or <computed>;
      restart_cmd = profile.restart_cmd or <computed>.
      notes: record the HAOS 2025.11 check_config path caveat when itype==haos.
      Return HostFacts.
  </action>
  <verify>uv run mypy src/haco/discover.py</verify>
  <acceptance_criteria>
    - discover() returns a fully-populated HostFacts or raises DiscoveryError
    - a profile override for config_dir/check/restart/install_type is used verbatim
  </acceptance_criteria>
  <done>mypy clean; override precedence implemented.</done>
