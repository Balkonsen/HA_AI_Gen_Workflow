<task type="auto">
  <name>Task 4: profile persistence</name>
  <files>src/haco/profile.py</files>
  <read_first>src/haco/models.py, src/haco/errors.py</read_first>
  <action>
    Implement:
      config_root() -> Path : POSIX uses $XDG_CONFIG_HOME/haco or ~/.config/haco;
        Windows uses %APPDATA%/haco. Create parents; chmod 0o700 on POSIX.
      profile_path(name) -> Path : config_root() / name + ".toml".
      save_profile(p) -> Path : write p.model_dump(exclude_none=True) as TOML via
        tomli_w. Atomic write (temp file + os.replace). chmod 0o600 on POSIX.
      load_profile(name) -> HostProfile : parse TOML with stdlib tomllib, build
        HostProfile; raise ProfileNotFound(name) when the file is absent.
      list_profiles() -> list[str] : sorted stems of *.toml in config_root().
    Defensive guard before writing: assert no dict key is password, token, or secret.
  </action>
  <verify>uv run pytest tests/test_profile.py -q</verify>
  <acceptance_criteria>
    - save_profile then load_profile returns an equal HostProfile
    - load_profile("nope") raises ProfileNotFound
    - the written .toml text contains neither "password" nor "token"
  </acceptance_criteria>
  <done>Round-trip test green.</done>
