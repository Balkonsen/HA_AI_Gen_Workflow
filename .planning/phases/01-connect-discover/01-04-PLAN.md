<task type="auto">
  <name>Task 2: permission preflight</name>
  <files>src/haco/preflight.py, src/haco/errors.py</files>
  <read_first>src/haco/discover.py</read_first>
  <action>
    Add PreflightError(HacoError).
    frozen dataclass PreflightResult(ok: bool, can_write_config: bool,
    can_restart: bool, findings: list[str]).
    async permission_preflight(client, facts) -> PreflightResult :
      write check: run f"test -w {shlex.quote(facts.config_dir)}"; if 0, also try
        f"touch {dir}/.haco_wtest && rm {dir}/.haco_wtest" and require exit 0.
      restart check: derive the restart binary (first token of facts.restart_cmd).
        If it is "ha" or "docker" or "systemctl": run f"command -v {bin}" (0 = present)
        AND, when the command would need root and user != root, run "sudo -n true"
        (0 = passwordless sudo available). Record which condition failed.
      ok = can_write_config and can_restart. findings lists each failed check with the
      exact remediation ("SSH user needs write on <dir>", "passwordless sudo required for
      <restart_cmd>", "<bin> not found on PATH").
  </action>
  <verify>uv run pytest tests/test_preflight.py -q</verify>
  <acceptance_criteria>
    - writable dir + available restart bin -> ok True
    - non-writable dir -> ok False, finding names the dir
    - missing sudo for a root-needing restart -> ok False, finding mentions sudo
  </acceptance_criteria>
  <done>test_preflight.py green.</done>
</task>

  <read_first>src/haco/ssh.py, src/haco/discover.py, src/haco/check.py, src/haco/preflight.py</read_first>
  <action>
    frozen dataclass ConnectReport(facts: HostFacts, preflight: PreflightResult,
    check: CheckResult, ready: bool).
    async connect_and_probe(profile, *, password_provider=None) -> ConnectReport :
      async with SSHClient(profile, password_provider=password_provider) as c:
        facts = await discover(c, profile)
        pf = await permission_preflight(c, facts)
        chk = await run_config_check(c, facts)
      ready = pf.ok and chk.ok
      return ConnectReport(facts, pf, chk, ready)
    Do not raise on pf/chk failure - return the report; the CLI decides the exit code.
    Let ConnectionError / AuthError / DiscoveryError propagate.
  </action>
  <verify>uv run pytest tests/test_connect.py -q</verify>
  <acceptance_criteria>
    - a healthy scripted host -> ConnectReport.ready is True
    - failing preflight OR failing check -> ready is False (report still returned)
  </acceptance_criteria>
  <done>test_connect.py green.</done>
