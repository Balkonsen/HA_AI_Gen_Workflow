<task type="auto">
  <name>Task 2: SSHClient wrapper</name>
  <files>src/haco/ssh.py</files>
  <read_first>src/haco/models.py, .planning/research/STACK.md</read_first>
  <action>
    Implement an async SSHClient built around asyncssh:
      __init__(profile: HostProfile, *, password_provider: Callable[[], str] | None = None)
      async connect() -> None : call asyncssh.connect(host, port=, username=,
        client_keys=[key_path] if auth==key else None,
        password=<resolved> if auth==password else None,
        known_hosts=<path> or None). Wrap asyncssh.PermissionDenied -> AuthError,
        asyncssh.HostKeyNotVerifiable / known-hosts errors -> HostKeyError,
        OSError/asyncssh.Error (connect) -> ConnectionError. Store the connection.
      resolve_password(): password_provider() if given; else os.environ["HACO_SSH_PASSWORD"];
        else if sys.stdin.isatty() getpass.getpass(f"SSH password for {user}@{host}: ");
        else raise AuthError("no password available (set HACO_SSH_PASSWORD)").
      async run(cmd: str, *, check: bool = False) -> CmdResult : run via
        conn.run(cmd, check=False); return CmdResult(exit_status, stdout, stderr).
        If check and exit_status != 0 raise RemoteCommandError with cmd + stderr tail.
      sftp() -> async context yielding conn.start_sftp_client() (used by later phases).
      async close() / __aenter__ / __aexit__.
    CmdResult is a frozen dataclass: exit_status:int, stdout:str, stderr:str.
  </action>
  <verify>uv run mypy src/haco/ssh.py</verify>
  <acceptance_criteria>
    - ssh.py defines SSHClient with async connect/run/close and __aenter__/__aexit__
    - password is never read from HostProfile
    - asyncssh.PermissionDenied is translated to AuthError
  </acceptance_criteria>
  <done>mypy clean; wrapper API present.</done>
</task>
